# Trunk is the default git mode

Work stays on whatever branch is checked out. Nothing is branched and nothing is merged, so
the first authority tier stays dormant because there is no merge to ask about.

**Why not branch-per-item.** Creating a branch is a decision about how a team works, and a
workflow that makes it silently produces branch sprawl in repositories that never wanted it.
The system it was adapted from branched automatically, and that was the single most
disliked behaviour.

**What would change this.** Nothing about the default. The other modes exist for projects
that want them, and switching is one setting.

**Reversed:** no.
