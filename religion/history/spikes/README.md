# Spikes

One file per question answered by `spike`, named for the question. Written by
`spike` itself, not by `complete`: a spike is not a work item and nothing is
ticked when one lands.

The code a spike wrote is gone by the time the file exists. What is kept is the question, the
answer, the evidence that decided it, and what is still unknown, so that the same question is
not paid for twice.
