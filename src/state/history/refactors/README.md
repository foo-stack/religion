# Completed refactors

One file per completed campaign, named for the area and the lens it covered. Written by
{{cmd:complete}}.

A campaign is not a build-plan item, so these carry no number and nothing is ticked when one
lands. They are kept apart from fixes because they answer a different question: not what went
wrong here, but what has already been simplified, so a later run does not repeat work or
undo a decision it cannot see.
